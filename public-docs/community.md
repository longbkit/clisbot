# Related projects

These projects are related to Clisbot and built by the community.

## Plugin directory

[clisbot.cafe](https://clisbot.cafe) is a community-run directory of Clisbot plugins. Listings are generated
from each plugin's public repository, so it is the fastest way to see what people are building and to
publish your own. It is independent of the Clisbot project and nothing on it is reviewed or endorsed by
us, so read a plugin's source before installing it.

## Tools and integrations

| Project                                                                                          | What it does                                                                                                                         |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| [Clisbot for VS Code](https://marketplace.visualstudio.com/items?itemName=hinnes.clisbot-vscode) | Opens the matching Clisbot project or worktree in VS Code and adds agent chat, file mentions, and editor links.                      |
| [VS Code Web plugin](https://github.com/itsjustanks/clisbot-plugin-vscode-web)                   | Opens a live Clisbot worktree in `vscode.dev` through a VS Code tunnel, including workspaces on headless hosts.                      |
| [Clisbot Icon](https://github.com/gpambrozio/clisbot-menubar)                                    | Shows workspace status across Clisbot hosts in the macOS menu bar and opens a workspace with one click.                              |
| [Clisbot Cross-Daemon Comms](https://github.com/xpufx/clisbot-cross-daemon-comms)                | Lets agents communicate with agents on another Clisbot daemon through an MCP server.                                                 |
| [Clisbot Antigravity ACP](https://github.com/tiezbro/clisbot-agy-acp)                            | Connects Google Antigravity CLI to Clisbot through ACP, with Clisbot-specific context, permissions, and concurrency handling.        |
| [Desvio](https://github.com/cleiter/desvio)                                                      | Rebuilds a personal fork from a set of branches, using an agent to resolve new conflicts and Git rerere to replay known resolutions. |

## Hosting and infrastructure

| Project                                                                | What it does                                                                                           |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [Clisbot Self-hosted](https://github.com/blockfeed/clisbot-selfhosted) | Packages the Clisbot web UI and a local daemon as a Docker deployment.                                 |
| [Devbox Fleet](https://github.com/omrihaviv/devbox-fleet)              | Provisions and maintains per-developer GCP devboxes with Clisbot, coding agents, and Tailscale access. |
