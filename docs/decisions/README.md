# Product and architecture decisions

This folder records decisions that change how Clisbot is structured or behaves, with dates, so later work can trace why the product looks the way it does. Feature docs under `docs/features/` describe the current behavior; files here hold the reasoning, the alternatives and the decision history.

## Milestone 2026-10 — Navigation V2, offline-first and Hub control plane

Between 2026-10-24 and 2026-10-26 Clisbot moved from one mixed sidebar to a scalable section-based navigation, started the offline-first program and set the long-term Hub architecture. The integration branch for this milestone is `integration/nav-v2-offline-o1` (Navigation V2 + Offline O1 + global search scope).

### Decision log

| Date       | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-25 | Desktop primary **rail** (icon + short label) and mobile tabs **Home · Chats · Workspace · Schedules · More**. Each section owns its header, quick filters, list and detail. No global search bar or global New row; search and New are section-header icons; ⌘K opens search.                                                                                                                                                                           |
| 2026-10-25 | **Inbox is removed as a destination; Home absorbs it.** Home order: composer at top, then quick starts, scope tabs, quick-filter chips, the existing display/filter row, the user's pins as tags, and the feed. `/sessions` redirects to Home.                                                                                                                                                                                                           |
| 2026-10-25 | The old sidebar's Pinned/Bots/Groups/Projects sections are retired. **Chats** is one Telegram-style list mixing Bot DMs and groups. Pinned rows float to the top with a pin mark; there is no separate pinned group anywhere.                                                                                                                                                                                                                            |
| 2026-10-25 | **For me / Others / All** ship in Round 1. For me = items the signed-in user created, plus local/sandbox items with unknown or no author. Watch is Round 2. Others' failures never appear in For me.                                                                                                                                                                                                                                                     |
| 2026-10-25 | **Failure lifecycle:** unseen → seen (collapsed, no badge) → leaves Failed on recovery/retry/dismiss/archive or after being seen for 7 days; mark-unread; a new occurrence resurfaces. Needs-action follows the same seen rule.                                                                                                                                                                                                                          |
| 2026-10-25 | **Automations → Schedules** (VI: Lịch), a calendar-centric surface later. **Tasks** shows on the rail/More as "In development".                                                                                                                                                                                                                                                                                                                          |
| 2026-10-25 | Feature flag `NAVIGATION_V2_ENABLED` is removed as the **first task after acceptance plus one stable release with 7 days and no rollback**.                                                                                                                                                                                                                                                                                                              |
| 2026-10-25 | Every change follows existing cross-platform patterns from the first commit; mobile must feel native and smooth; acceptance includes native iOS/Android smoke.                                                                                                                                                                                                                                                                                           |
| 2026-10-25 | Offline-first order **O1 → O2 → O3**. The unit of failure is one source, never the app. Default client cache caps: 500 MB mobile / 2 GB desktop / 300 MB web. Queued approvals require re-confirmation after reconnect.                                                                                                                                                                                                                                  |
| 2026-10-25 | **Global search** is global. Containers (Host/Hub/Project) become scope chips; items open. Opening an item never changes the view filter silently; "Show in Workspace" replaces the filter, with Undo.                                                                                                                                                                                                                                                   |
| 2026-10-26 | **Tabs on mobile:** no ad-hoc "keep Home alive". Measure on native first. If needed, use a real tab navigator with lazy mount + `freezeOnBlur` + focus-gated data for all tabs.                                                                                                                                                                                                                                                                          |
| 2026-10-26 | **Always through a Hub.** Personal users run a personal Hub; one Hub per user is encouraged. The Hub is the control plane (inventory, access, activity feed, push) and **not** the data plane. Previews are metadata-only or device-encrypted (never plaintext on the Hub). Feed events are user-friendly content only (final replies, others' messages, needs-me prompts, finished/failed). See ADR-001.                                                |
| 2026-10-26 | **Naming:** the section formerly "Work" is **Workspace** (EN and VI). The Home mode switch is **Chat · Workspace · All** ("Hybrid" removed). Task management is **Tasks** (VI **Công việc**); in Vietnamese "Công việc" means Tasks only, and no locale may use the same word for Workspace and Tasks.                                                                                                                                                   |
| 2026-10-26 | **Workspace list rules:** scope first, pins reorder only inside the scope. Quick chats follow the same rules (one "Quick chat" project in Project grouping; interleaved by last update otherwise; no separate section). No "Show more" collapse. Bot sessions are shown by default, with a quick "Bots" toggle chip; the "Active" filter is removed. A session is a Chat session iff it carries a Bot label; Home mode, counts and search use that rule. |
