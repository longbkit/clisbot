# Plan — Offline / Freshness roadmap after ADR-001

- Date: 2026-10-26 · Status: **plan only, nothing scheduled or dispatched.** Starts after the Owner accepts the current integration build and approves ADR-001.
- Order rule: client-only phases first (independently shippable), then Hub/daemon phases behind the ADR.
