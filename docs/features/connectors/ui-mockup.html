Connectors — UI mockup

Every surface uses the same row: logo, name, a muted summary after a dot, one trailing control. Details live one level down, in a sheet opened from the row, as on the Providers page. Section help is the info tip, never a paragraph under the header. Remove is an outline button inside the sheet, confirmed.
