**Claude Cowork 및 AI 데스크톱 앱의 대안.** 사무 업무와 소프트웨어 엔지니어링을 위한 데스크톱 작업 공간입니다. 주제 조사, 데이터 분석, 문서 작성부터 소프트웨어 계획, 구현, 테스트, 리뷰까지 대화, 파일, 코드를 한곳에서 다루세요. 에이전트 제공자와 모델을 직접 선택하고 기존 구독이나 API 키를 사용할 수 있습니다.

**OpenClaw 및 Hermes Agent의 대안.** 내 컴퓨터에서 에이전트를 실행하고, 지속적으로 활용할 컨텍스트와 재사용 가능한 스킬, 실행에 필요한 도구를 제공하세요. 작업을 위임하고, 반복 작업을 예약하고, 워크플로를 자동화하면서 진행 상황과 결과를 확인할 수 있습니다. 개인적으로 사용하거나 프로젝트, 제공자, 모델별 접근 권한을 관리하며 팀과 함께 사용할 수 있습니다.

**Grok Bot, Muse, Dots의 대안.** 업무와 개인 생활을 위한 나만의 봇을 여러 개 만드세요. 각 봇의 역할, 페르소나, 메모리, 도구, 동작 방식과 실행 위치를 직접 정할 수 있습니다. 조사, 계획, 개발, 리뷰 등 서로 다른 전문성을 가진 봇들을 하나의 그룹 채팅에 모으세요. 공동 목표를 주고 아이디어 토론, 작업 조율, 상호 검토를 맡겨 더 완성도 높은 결과를 함께 만들어 가도록 할 수 있습니다. Clisbot에 내장된 채팅에서 봇과 대화하고, 평소 사용하는 소통 채널에서도 AI를 이용하세요. 노트북 앞에서도 이동 중에도 사용할 수 있습니다.

- **셀프 호스팅:** 에이전트는 완전한 개발 환경이 갖춰진 내 컴퓨터에서 실행됩니다. 평소 쓰던 도구, 설정, 스킬을 그대로 쓸 수 있습니다.
- **에이전트 선택의 자유:** 40개가 넘는 에이전트 옵션을 제공합니다. 기본 지원하는 Claude Code, Codex, Copilot, OpenCode, Pi, Antigravity, Muse Code에 더해 Grok을 포함한 ACP 카탈로그 프리셋 38개를 이용할 수 있습니다. 작업마다 모델을 선택하세요.
- **음성 제어:** 음성 모드에서 작업을 말로 지시하거나 문제를 음성으로 함께 검토할 수 있습니다. 손을 쓰지 않고 작업해야 할 때 유용합니다.
- **여러 기기 지원:** iOS, Android, 데스크톱, 웹, CLI를 지원합니다. 데스크톱에서 시작해 휴대폰으로 확인하고 터미널에서 자동화할 수 있습니다.
- **개인정보 보호 우선:** Clisbot는 텔레메트리, 추적, 강제 로그인을 사용하지 않습니다.

## 컨셉

Clisbot는 Paseo의 여러 기기용 에이전트 작업 공간과 OpenClaw의 채널 연동 및 채널 고유 기능을 결합합니다. Paseo의 핵심은 선택의 자유입니다. 작업마다 Claude Code, Codex, Copilot, OpenCode, Pi 중에서 에이전트 실행 환경과 모델을 선택하고, 업무 방식이 달라지면 제공자를 바꿀 수 있습니다. 이를 바탕으로 사무 업무와 소프트웨어 엔지니어링을 위한 데스크톱 AI 작업 공간, 작업 위임과 자동화를 위한 에이전트 플랫폼, 업무 및 개인 생활을 위한 봇을 하나로 연결합니다. AI를 앱의 기본 기능으로 제공하고 모든 소통 채널에서 이용할 수 있도록 하는 것이 목표입니다. 에이전트는 Host에서 실행되고, 사용자는 앱이나 팀 대화에서 작업을 확인하고 지시할 수 있습니다.

Clisbot는 봇 생성과 그룹 협업을 앱의 기본 기능으로 제공합니다. 전문 역할, 지침, 모델이 서로 다른 봇을 빠르게 만들고 하나의 그룹에 모아 작업을 완수하거나, 아이디어를 브레인스토밍하거나, 서로의 결과물을 검토하게 할 수 있습니다. 참여자, 그룹 공통 지침, 응답 규칙, 토론 횟수 제한을 앱에서 직접 설정하고 필요할 때 토론의 방향을 바꾸거나 중단할 수 있습니다. 외부 채팅 앱의 인터페이스와 봇 제약을 통해 협업을 구성할 때보다, 앱 자체의 그룹에서는 봇의 협업 방식을 더 직접적이고 주도적으로 제어할 수 있습니다.

전문 업무와 기업 환경을 위해 Clisbot는 Hub에서 관리하는 Host와 접근 제어를 추가합니다. Member와 Team에 부여한 권한으로 사용할 수 있는 Host와 Project, 에이전트에 허용되는 제공자와 모델을 지정할 수 있습니다. 팀은 관리형 Host를 공유하면서 사용자별 접근 범위를 다르게 설정할 수 있습니다.

## 저는 누구이며, 왜 이 프로젝트를 만들었나요

저는 Vexere의 공동 창업자이자 CTO인 Long Luong(Long)입니다. Vexere는 베트남 1위 교통 예약 플랫폼이며, 운송 사업자를 위한 SaaS와 예약 재고 유통 인프라도 구축하고 있습니다. 회사가 300명, 엔지니어링·프로덕트·디자인 팀이 100명 규모로 성장하는 과정에서, 조직 전체에 AI 중심 워크플로를 도입할 가장 실용적인 방법을 찾고 있었습니다.

문제는 AI가 유용한지 여부가 아닙니다. 파편화되고 비용이 높으며 통제하기 어려운 기술 구성을 만들지 않으면서, 기업 규모에서 AI를 어떻게 작동하게 할 것인가입니다. 실제로는 비용 통제, 워크플로가 실제 실행 상황을 정확히 보여 주는지, 팀이 쉽게 사용할 수 있는지, 거버넌스, 그리고 사람들이 이미 일하고 있는 도구와 소통 채널에 최첨단 AI를 연결하는 방법을 동시에 해결해야 합니다.

그렇게 도달한 접근 방식이 clisbot입니다. 또 하나의 고립된 AI 계층을 만드는 대신, 이미 신뢰하는 코딩 CLI를 지속적으로 작동하고 채팅을 기본 접점으로 사용하는 에이전트로 바꿉니다. 이를 Slack, Telegram, Zalo 등의 채널과 실제 팀 워크플로에서 활용할 수 있습니다.

clisbot가 여러분의 워크플로에 도움이 된다면 GitHub Star로 알려 주세요. 프로젝트가 유용하다는 것을 알 수 있고, 더 많은 사람이 발견하는 데에도 도움이 됩니다.

## 시작하기

Clisbot는 코딩 에이전트를 관리하는 로컬 서버인 데몬을 실행합니다. 데스크톱 앱, 모바일 앱, 웹 앱, CLI 같은 클라이언트가 이 데몬에 연결합니다.

### 준비 사항

아래 에이전트 CLI 중 하나 이상을 설치하고 인증 정보를 설정해야 합니다.

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
- [Codex](https://github.com/openai/codex)
- [GitHub Copilot](https://github.com/features/copilot/cli/)
- [OpenCode](https://github.com/anomalyco/opencode)
- [Pi](https://pi.dev)

### 데스크톱 앱(권장)

[clisbot.com/download](https://clisbot.com/download) 또는 [GitHub 릴리스 페이지](https://github.com/longbkit/clisbot/releases)에서 다운로드하세요. 앱을 열면 데몬이 자동으로 시작됩니다. 별도로 설치할 것은 없습니다.

휴대폰에서 연결하려면 **설정 → 호스트 → 기기 페어링**을 여세요.

### CLI / 헤드리스 환경

CLI를 설치하고 Clisbot를 시작하세요.

```bash
npm install -g @clisbot/cli
clisbot
```

Clisbot가 로컬에서 시작된 뒤 기기 페어링을 위한 종단 간 암호화 릴레이를 켤지 묻습니다. 거절하면 TCP, Tailscale 또는 다른 VPN으로 직접 연결할 수 있습니다. 이 방식은 서버나 원격 머신에서 유용합니다.

자세한 설치와 설정은 아래 문서를 참고하세요.

- [문서](https://clisbot.com/docs)
- [연결 가이드](https://clisbot.com/docs/connectivity)
- [설정 레퍼런스](https://clisbot.com/docs/configuration)

### Docker

Docker에서 Clisbot 데몬과 셀프 호스팅 웹 UI를 실행하세요:

```bash
docker run -d --name clisbot \
  -p 6868:6868 \
  -e CLISBOT_PASSWORD=change-me \
  -v "$PWD/clisbot-home:/home/clisbot" \
  -v "$PWD:/workspace" \
  ghcr.io/longbkit/clisbot:latest
```

컨테이너가 시작되면 `http://localhost:6868`을 여세요. 사용하는 에이전트 CLI를 기본 이미지에 추가한 뒤, 환경 변수나 영구 `/home/clisbot` 볼륨으로 인증 정보를 설정하세요. 자세한 내용은 [Docker 문서](docs/docker.md)를 참고하세요.

## CLI

앱에서 할 수 있는 모든 작업은 터미널에서도 할 수 있습니다.

```bash
clisbot run --provider claude/opus-4.6 "implement user authentication"
clisbot run --provider codex/gpt-5.4 --worktree feature-x "implement feature X"

clisbot ls                           # 실행 중인 에이전트 목록
clisbot attach abc123                # 실시간 출력 스트리밍
clisbot send abc123 "also add tests" # 후속 작업 전송

# 원격 데몬에서 실행
clisbot --host workstation.local:6868 run "run the full test suite"
```

자세한 내용은 [전체 CLI 레퍼런스](https://clisbot.com/docs/cli)를 참고하세요.

## 스킬

스킬은 에이전트가 Clisbot를 통해 다른 에이전트를 오케스트레이션하는 방법을 알려 줍니다.

```bash
npx skills add longbkit/clisbot
```

그런 다음 어떤 에이전트 대화에서든 아래 명령을 사용할 수 있습니다.

- `/clisbot-handoff` — 에이전트 간에 작업을 넘깁니다. Claude로 계획을 세운 뒤 Codex에 구현을 넘길 때 이 기능을 씁니다.
- `/clisbot-advisor` — 작업 자체를 넘기지 않고, 에이전트 하나를 조언자로 띄워 두 번째 의견을 받습니다.
- `/clisbot-committee` — 서로 다른 관점의 에이전트 두 개로 위원회를 구성해, 한 발 물러나 근본 원인을 분석하고 계획을 세웁니다.

## 개발

모노레포 패키지 구성은 다음과 같습니다.

- `packages/server`: Clisbot 데몬(에이전트 프로세스 오케스트레이션, WebSocket API, MCP 서버 제공)
- `packages/app`: Expo 클라이언트(iOS, Android, 웹)
- `packages/cli`: `clisbot` CLI(데몬과 에이전트 워크플로)
- `packages/desktop`: Electron 데스크톱 앱
- `packages/relay`: 데몬과 클라이언트가 쓰는 릴레이 전송 및 암호화 패키지
- `packages/website`: 마케팅 사이트 및 문서(`clisbot.com`)

자주 쓰는 명령:

```bash
# 모든 로컬 개발 서비스 실행
npm run dev

# 개별 환경 실행
npm run dev:server
npm run dev:app
npm run dev:desktop
npm run dev:website

# 서버 스택 빌드
npm run build:server

# 레포 전체 검사 실행
npm run typecheck
```
