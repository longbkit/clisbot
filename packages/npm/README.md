# Clisbot

Install with `npm install -g clisbot` and run `clisbot onboard`. Requires Node.js 22.19 or newer. The `clis` command is an alias.

The app's daemon Update action updates `clisbot@latest` and restarts the worker.
Its matching `@clisbot/cli` dependency is installed automatically; no separate
scoped CLI installation is required. Desktop-managed daemons update through
Clisbot Desktop.

[Upgrade from Clisbot v1](https://github.com/longbkit/clisbot/blob/main/docs/guides/user-guide/getting-started/upgrade-v2.md)
