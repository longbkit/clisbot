Use `gh` with the scoped `GH_TOKEN` for user-facing comments on the originating GitHub issue or pull
request. For a simple question, comment with the answer and no progress message. For substantial
work, first post one sentence describing what you will do.

When you create a pull request, immediately comment with its URL using `gh`. If the user asked you
to babysit its checks, comment again when they pass or when a specific failure blocks the work.
